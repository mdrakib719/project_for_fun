# 📸 Image Gallery

A **Modern Card-Style Image Gallery** built with **HTML**, **CSS**, and **JavaScript**. This project allows users to view a collection of images with smooth and simple navigation controls.

## ✨ Features

- 🎨 Clean and responsive card-style UI
- 🌅 Beautiful gradient background for a modern feel
- 🖼️ One-image-at-a-time viewer with navigation buttons
- 💡 Smooth transitions and hover effects

## 🛠️ Built With

- **HTML5** – Markup structure
- **CSS3** – Styling (Flexbox, gradients, rounded corners, etc.)
- **JavaScript** – Logic for image navigation
